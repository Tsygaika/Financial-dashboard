### Постановка задачи
Поступил заказ от клиента: необходимо по таблице Finances.xlsx построить дашборд со следующими графиками:
- лист "расходы" необходимо отобразить, как столбчатую диаграмму, на которой можно посмотреть расходы по нескольким категориям или по всем сразу. Также можно посмотреть за конкретный год или за все время.
- лист "доходы" - аналогичная задача.
- по брокерским счетам("Счёт 1" и "Счёт 2") нужны общие графики, на которых можно посмотреть информацию по обоим счетам или по одному конкретному счету. Содержание графиков: вложенная сумма, сумма активов, объем ежемесячных пополнений, изменения месячной доходности и доходности за все время. Также, используя вкладку "Акции", нужно создать диаграмму с долями каждого актива в конкретном портфеле.
- для листа "Вклады" нужно построить графики: суммы активов, суммы ежемесячного дохода, ежемесячной доходности.
- для всего капитала(лист "Активы") нужно построить график, который показывает структуру капитала на каждый месяц. Должна быть возможность смотреть отдельно по годам и по категориям активов.

### Решение задачи
Так как клиент хочет, чтобы обновление данных занимало минимум усилий, то было принято решение создать скрипты, который парсят данные по структуре каждого листа таблицы(сейчас формат таблицы не подходит для работы с дашбордом). Скрипты лежат в папке subscripts - для каждого листа свой отдельный скрипт. Все скрипты запускаются из main.py, а данные, которые в них попадают заранее обрабатываются функцией excel_to_arrays, которая преобразует данные в более удобный для обработки формат.

После парсинга формируется 6 файлов(они лежат в папке output) - по 1 на каждый лист. Эти файлы автоматически отправляются на Яндекс.Диск в [папку](https://disk.yandex.ru/d/oLQt002uvnvGTw). К каждому файлу этой папки было создано подключение в Datalens с автоматическим обновлением данных. Далее были созданы датасеты, чарты и [сам дашборд](https://datalens.yandex/plivlmya0r069) (в данный момент он не публичный).


*Примечание: все данные в таблице Finances.xlsx являются выдуманными.*
